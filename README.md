One line, 140 characters at most, roasting my own AI agent. An AI judge compares the lines two at a time and the funniest takes the biggest share of the reward.

> My agent spent six tool calls planning to plan, then asked me what I wanted in the first place.

## Run it

```sh
python3 main.py
```

Writes the line to `<MAKEFUN_OUTPUT_DIR>/entry.txt` (default `/output/entry.txt`). Standard library only, deterministic, no network.
